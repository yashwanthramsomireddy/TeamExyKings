Built to be safe first

Debloating should never feel like a gamble. Every action is scoped to your user profile and can be undone.

🔌No root needed

Uses Android's standard ADB interface and --user 0 operations only. Nothing on the system partition is modified.

🛡️Safety ratings

Every known package is rated Safe, Recommended, Caution, Locked or Core, with a plain-English description of what it does.

⛔Core-app guard

Critical system apps live in their own tab, never bulk-selected, and ask for an explicit confirmation one by one.

↩️One-click re-enable

Restores disabled and uninstalled apps while your phone is connected. Smart restore picks the right command for each app.

💾Automatic backups

A JSON snapshot of package states is saved before every action, plus a Panic Restore button to re-enable everything from the latest backup.

⚡Fast single scan

One batched ADB call loads System, User and 3rd-party apps and sorts them into tabs. Tab switching is instant, even with 500+ packages.

📱Era-aware

Detects your Android / One UI version and only shows packages that apply to your device generation, from legacy TouchWiz to the newest One UI.

🔐Handles locked apps

On One UI builds that block the normal command, DebloatKit automatically falls back to the user-0 refresh method.

🎨Four themes

Green, Blue, Purple and White — switch instantly without restarting.

How it works

From a fresh phone to a cleaner phone in a few minutes.

Turn on USB debuggingSettings → About phone → Software information → tap Build number 7 times. Then Settings → Developer options → USB debugging → ON.
Connect and allowPlug in via USB and tap Allow on the phone when asked. DebloatKit detects your Galaxy automatically.
ScanClick Scan once. Your apps are sorted into System, Core, User and 3rd Party tabs. Nothing is pre-selected.
Select and applyTick what you don't need, then Disable or Uninstall. A backup is saved first.
Changed your mind?Select the apps and press Re-enable Selected — or use Panic Restore in Settings.
Turn USB debugging offWhen you're done, switch USB debugging back off in Developer options and unplug the cable.
⚠ Leave USB debugging off when you're not using it. It is a developer feature and gives a connected computer elevated access to your phone.

What the ratings mean

A rating is guidance based on community knowledge. It is not a guarantee for every phone, carrier build or firmware.

Safe

Non-essential bloat, telemetry or promotional apps.

Recommended

Commonly removed, with a small benefit such as fixing a known issue.

Caution

May remove a feature you use. Read the description first.

Locked

Blocked on newer One UI builds; uses the user-0 refresh method.

Core

Framework or security component. Separate tab, per-app confirmation.

Keep

Protected and cannot be selected.

FAQ

Short answers to the usual questions.

Do I need to root my phone?

No. DebloatKit only uses ADB shell commands that act on your user profile (--user 0). No root and no bootloader unlock.

Is it really reversible?

Disabled apps are re-enabled with pm enable. Uninstalled apps are brought back with pm install-existing --user 0, because the original APK stays in the system partition. A factory reset also restores everything.

Will it affect my warranty or Samsung Knox?

DebloatKit doesn't root, flash or modify the system partition. Policies differ between regions and carriers though, and we can't speak for the manufacturer, so check your own warranty terms before making changes.

Which phones does it support?

Samsung Galaxy phones and tablets from Android 5.0 to current One UI releases. The package list is split into three generations — legacy TouchWiz, One UI 1–5.1 and One UI 6 onward. Other brands aren't supported.

An app I removed broke something. What now?

Open the tab, tick the app and press Re-enable Selected. If you're not sure which app it was, use Panic Restore in Settings to re-enable everything from the latest backup.

Does DebloatKit collect any data?

No. It has no accounts, analytics or telemetry and makes no network connections of its own. See the Privacy Policy.

Windows says "unknown publisher" or SmartScreen warns me.

The installer isn't code-signed, so Windows may show a warning for new downloads. Download only from the official GitHub releases page.

Do I need to install ADB separately?

Yes — install Google's Platform Tools and make sure adb is on your PATH, or point DebloatKit at adb.exe in Settings → ADB Configuration. The Test ADB button tells you whether it works.
