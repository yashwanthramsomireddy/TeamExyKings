Short version: this theme does not collect, store, or transmit any of your personal data, chat content, or usage information. There is nothing to opt out of because nothing is collected.

What this theme is

TeamExyKings Pitch Black Theme is a static color configuration file (a .tdesktop-theme file for Telegram Desktop and a .attheme file for Telegram for Android). It changes how the Telegram app looks on your device. It is read locally by the Telegram app itself and does not run any code, connect to the internet, or communicate with any server operated by TeamExyKings.

Data we collect

None. Applying this theme does not give TeamExyKings — or anyone else — access to your messages, contacts, account information, or device data. The theme file contains only color values and a small background image; it has no ability to read or send information.
