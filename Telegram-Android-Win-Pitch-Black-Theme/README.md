# TeamExyKings Pitch Black Theme

A true AMOLED pitch-black (`#000000`) theme for Telegram, built for both
**Telegram Desktop** and **Telegram for Android**, with white text and
monochrome accents throughout.

This is an **independent, unofficial, custom theme**. It is not made by,
affiliated with, or endorsed by Telegram or Telegram FZ-LLC. No Telegram
logos, icons, or branding are included or used anywhere in this repository —
every asset here (color palette, background image, naming) is original to
**TeamExyKings**.

| File | Platform |
|---|---|
| `Desktop/TeamExyKings Pitch Black Theme.tdesktop-theme` | Telegram Desktop (Windows / macOS / Linux) |
| `Android/TeamExyKings Pitch Black Theme.attheme` | Telegram for Android |

The Desktop file is a ZIP archive containing:
- `colors.tdesktop-theme` — the full color palette (539 keys covering the
  window chrome, chat list, message bubbles, calls, media viewer, wallet,
  sidebar, and more)
- `background.png` — a solid black wallpaper, so the chat background renders
  true black instead of falling back to Telegram's default pattern

The Android file is a single `.attheme` palette file (541 keys).

## Design

- Every background surface: pure `#000000`
- Primary text and icons: `#ffffff`
- Secondary/muted text: mid-grey
- Red reserved only for destructive or attention actions (close button
  hover, hang-up, error states) — everything else is strictly monochrome

## Installation

### Telegram Desktop
1. Download `Desktop/TeamExyKings Pitch Black Theme.tdesktop-theme` from
   this repo and send it to yourself (e.g. in Saved Messages), or open it
   directly from your downloads folder.
2. Click the file inside Telegram Desktop.
3. In the **Theme Preview** window, click **Apply This Theme**, then
   **Keep Changes**.

### Telegram for Android
1. Download `Android/TeamExyKings Pitch Black Theme.attheme` from this
   repo and send it to yourself (e.g. in Saved Messages), or open it from
   your downloads folder.
2. Tap the file to open the theme preview.
3. Tap **Apply**.
