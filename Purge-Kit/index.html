PurgeKit

A free Windows cleaner for temporary files, browser and app caches — with a software updater built in. Clear, transparent, no ads.

Download for Windows View on GitHub

Windows 10 / 11 · Free · No ads · No account

What it does

140+ cleaning tasks

System, user, browser and third-party app caches (games, chat apps, Adobe, media, dev tools) across 11 phases.

You choose what goes

Safe defaults are pre-selected. Every task can be toggled, and a whitelist protects folders you want kept.

Silent mode

Right-click the Recycle Bin and choose Run PurgeKit Cleaner. A tray icon shows progress and an optional stop.

Software Updater

Finds outdated apps through winget and downloads the official installer. You run it — nothing installs silently.

Full log of every run

See each task, its time and how much space it freed. Logs stay on your PC.

Safe by design

No task runs longer than 120 seconds, you can cancel any time, and settings lock while a purge is running.

Get started

  1. Download Setup_PurgeKit from the latest release.
  2. Run the installer and pick a folder (the default is fine).
  3. Open PurgeKit, review the Junk Scan results, then press Purge.
Administrator rights: PurgeKit asks for administrator permission because many system cache locations can only be cleaned that way.

Your privacy in short

PurgeKit has no accounts, no analytics and no tracking. What it scans and removes stays on your PC. Read the full Privacy Policy and Terms of Service.
