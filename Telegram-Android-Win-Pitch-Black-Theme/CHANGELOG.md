# Changelog

All notable changes to the TeamExyKings Pitch Black Theme are documented in
this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0] - 2026-11-07

### Added
- Initial public release of **TeamExyKings Pitch Black Theme** for Telegram
  Desktop and Telegram for Android.
- Desktop palette (`colors.tdesktop-theme`) covering 539 color keys: window
  chrome, title bar, menus, chat list (normal/hover/active states), message
  bubbles, files and voice waveforms, compose area, media viewer, calls and
  group calls, wallet, and sidebar.
- Android palette (`.attheme`) covering 541 color keys for the full chat
  interface.
- Solid black `background.png` bundled into the Desktop theme archive so the
  chat wallpaper renders true black instead of the default pattern.
- Consistent monochrome design: `#000000` surfaces, `#ffffff` primary
  text/icons, grey secondary text, with red reserved only for
  destructive/attention UI (close button hover, hang-up, errors).
