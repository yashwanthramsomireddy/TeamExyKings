# Changelog

## 1.1.0 (versionCode 3) — 11 Nov 2026

- New Home screen: branded header with About (i), FAQ (?) and Settings icons, animated hero card, tool tiles (Merge tracks, Ringtone maker, Video to audio, Convert format) and richer recent files
- MP3 and other long files open far faster: the editor opens immediately and the waveform draws progressively (decoder loop and PCM copy optimised, waveform cached for next time, exact length corrected for VBR MP3s)
- New Merge tracks screen: add many files, reorder, trim each, gap or crossfade, mixed formats, save as one file
- Editor: Remove selection mode, undo/redo, exact time entry, cursor with Start here / End here, zoom buttons, loop, edge previews, quick 15/30/60 s select, Trim silence, file info
- Effects: volume ±24 dB, normalize, speed 0.5–2×, reverse (plus the existing fades)
- More output formats: Original (lossless cut for MP3, M4A/AAC and Opus), M4A, AAC (.aac), Opus (OGG), FLAC, WAV — with bitrate, sample rate and mono/stereo choices; FLAC/Opus shown only when the phone can encode them
- Save to Music, Ringtones, Notifications or Alarms; title/artist/album tags; Share after saving; cancel button during export
- Video to audio: pick a video and edit or save its sound
- Exactly 8 accent colours; Black is hidden on dark themes and White on the light theme; default theme Pitch Black with White accent
- Settings now has About and FAQ entries as well
- About: Visit Website opens teamexykings.in; policies and Share use teamexykings.in/King-Audio-Trimmer/; Credits updated
- FAQ rewritten for the new features
