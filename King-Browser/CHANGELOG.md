# Changelog

All notable changes to King Browser are documented here. This file tracks the current release only.

## [1.0.1] - 2026-11-11

- About and FAQ now also reachable as icon-labelled entries right next to Settings in the overflow (⋮) menu, in addition to their existing place inside Settings.
- Incognito tabs now block screenshots and hide app content in the Recents/app-switcher thumbnail (`FLAG_SECURE`), active only while a private tab is on screen.
- Policy links updated: Visit Website now points to `https://teamexykings.in/`; Privacy Policy and Terms of Service now point to the `King-Browser/` folder on the site.
- Confirmed: BTM already loads automatically on cold app launch (not just on "+" new tab) — the first tab the app opens on startup resolves to BTM's dashboard the same way a manual new tab does.
