How to apply it

Telegram Desktop

  1. Download the .tdesktop-theme file above and send it to yourself (e.g. Saved Messages), or open it from your downloads folder.
  2. Click the file inside Telegram Desktop.
  3. In the Theme Preview window, click Apply This Theme, then Keep Changes.

Telegram for Android

  1. Download the .attheme file above and send it to yourself (e.g. Saved Messages), or open it from your downloads folder.
  2. Tap the file to open the theme preview.
  3. Tap Apply.
